### Hi, I'm Wenbo

I'm a bioinformatician applying AI to medical genetics: variant classification, rare disease diagnostics, and precision medicine.

#### Selected work

- **[Genetic Counseling Skill Pack](https://github.com/muwenbo/genetic-counseling-skills)**: open agent skills for variant grading, phenotype-to-HPO conversion, disease inference and pedigree drawing, inside the agent apps you already use. ([write-up](https://www.viknox.com/en/insights/genetic-counseling-toolkit))
- **[Pedigree Studio](https://pedigree.viknox.com/)**: a no-install pedigree editor. The webpage is the software, and you or an agent can edit it. ([write-up](https://www.viknox.com/en/insights/disposable-pedigree-editor))
- **[CNV Pathogenicity Classifier](https://cnvclassifier.viknox.com/)**: rule-based ACMG/ClinGen CNV grading, with a web UI and an agent-callable interface. ([write-up](https://www.viknox.com/en/insights/cnv-classification))
- **[Knowledge-Graph REST API](https://github.com/muwenbo/genetic-counseling-skills/blob/main/docs/rest-api-contracts.md)**: a REST API over a gene-disease-phenotype knowledge graph, for phenotype analysis and variant verification. ([write-up](https://www.viknox.com/en/insights/graphrag-rare-disease))
